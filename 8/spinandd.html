SPINANDD(8) System Manager's Manual SPINANDD(8)

NAME

SPINANDDaemon — Daemon to store data on dedicated SPI NAND

SYNOPSIS

Takes no arguments, and users should not launch it manually.

DESCRIPTION

SPINANDDaemon Responsible for storing and maintaining data saved on SPINAND memory.

HISTORY

first appeared in macOS 14.0
