PerfPowerServices(8) System Manager's Manual PerfPowerServices(8)

NAME

PerfPowerServices — manages structured log archives that enable retrieval of system power and performance data.

DESCRIPTION

The PerfPowerServices daemon works only within the context of a launchd job and should not be run from the command line.
