NAME

odproxyd — OpenDirectory proxy daemon

SYNOPSIS

odproxyd [--version]

DESCRIPTION

The odproxyd launchd(8) job maintains incoming proxy connections to the local opendirectoryd(8) daemon. It should not be run manually.

SEE ALSO

odutil(1), opendirectory(8)
