CommCenter(8) System Manager's Manual CommCenter(8)

NAME

CommCenter — Provides functionality to allow the Mac to make and receive phone calls.

DESCRIPTION

CommCenter provides functionality to allow phone calls to be made and received on the Mac. See

https://support.apple.com/kb/PH18756

CommCenter should not be directly invoked.
