NAME

viewdiagnostic — Visualize diagnostic reports

SYNOPSIS

viewdiagnostic path

DESCRIPTION

viewdiagnostic translates crash reports and other diagnostic reports into a textual representation for improved visualization. Tools that parse data from the report should use its as-written format instead.
